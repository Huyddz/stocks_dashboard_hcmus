#  Real-Time Stock Analytics & Sentiment Dashboard

A web dashboard integrating real-time market data, interactive financial visualization, and financial sentiment analysis powered by FinBERT.

Developed as part of coursework / project portfolio at **VNUHCM - University of Science (HCMUS)**.

---

##  Key Features

- **Live Market Data Lookup:** Auto-completing ticker search using Yahoo Finance API endpoints to retrieve market cap, trading currency, and current prices.
- **Interactive Candlestick Charts:** High-performance hourly price and OHLC visualization built with Plotly.
- **Financial Statements Breakdown:** Quarterly and annual revenue vs. net income comparisons visualized using Altair.
- **NLP Sentiment Engine (FinBERT):** Uses a pre-trained Transformer (`yiyanghkust/finbert-tone` via PyTorch) to score financial news snippets as Positive, Neutral, or Negative, producing confidence-weighted trading suggestions (BUY / HOLD / SELL).
- **Cyberpunk UI & HUD Layout:** Custom CSS animations, dynamic particle effects, and responsive HUD-style components in Streamlit.

## Requirements
Prerequisites
Python 3.9+ installed

Recommended: GPU with CUDA support for faster transformer inference (CPU works as fallback)

Installation
Clone the repository:

Bash
git clone [https://github.com/Huyddz/stocks_dashboard_hcmus.git](https://github.com/Huyddz/stocks_dashboard_hcmus.git)
cd stocks_dashboard_hcmus
Create and activate a virtual environment:

Bash
python -m venv venv
# On macOS/Linux:
source venv/bin/activate
# On Windows:
venv\Scripts\activate
Install dependencies:

Bash
pip install streamlit streamlit-searchbox plotly altair yfinance pandas requests torch transformers
Launch the application:

Bash
streamlit run app.py
# Usage Guide
Search Stock: Enter a company name or ticker symbol (e.g., AAPL, MSFT, TSLA) in the search bar.

Examine Financials: Toggle between Quarterly and Annual tabs to inspect revenue growth and net profitability bars.

Run Sentiment Analysis:

Copy a headline or news snippet regarding the selected company into the text box.

Click Analyze Sentiment to view the sentiment classification, probability breakdown, and heuristic signal.

# Disclaimer
The sentiment-based recommendations (BUY / HOLD / SELL) generated by this tool are driven strictly by a language model heuristic and are intended for educational and analytical purposes only. They do not constitute financial advice.
